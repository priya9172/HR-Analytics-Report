# 📊 HR Analytics Dashboard

An interactive **Power BI HR Analytics Dashboard** built to analyze employee data, track workforce trends, and provide actionable insights into employee attrition. This project demonstrates data visualization, data modeling, and business intelligence skills using Power BI.

---

## 📌 Project Overview

The dashboard provides HR professionals and business stakeholders with a comprehensive view of workforce data. It helps identify attrition patterns, employee demographics, salary distribution, and department-wise performance through interactive visualizations.

---

## 🚀 Dashboard Features

- 📈 Employee Count
- 👨‍💼 Active Employees
- 📉 Attrition Count
- 📊 Attrition Rate (%)
- 🎂 Average Employee Age
- 💼 Average Years of Experience
- 🏢 Department-wise Employee Count
- 🔄 Attrition by Department
- 💰 Attrition by Salary Slab
- 👨‍👩‍👧 Attrition by Gender
- 📅 Age Group Distribution
- 📉 Attrition Trend by Experience
- 🧑‍💼 Job Role-wise Attrition Analysis
- 🎯 Interactive Department & Age Group Filters

## 🎯 Project Objectives

- Analyze employee attrition.
- Monitor workforce demographics.
- Compare department performance.
- Identify high-risk attrition groups.
- Build an interactive HR dashboard using Power BI.

---


## 📈 Insights

- Operations has the highest number of employees.
- Attrition is higher among employees in lower salary slabs.
- Most employees belong to the 26–35 age group.
- Attrition trends decrease with increasing experience.
- The dashboard enables quick analysis using interactive filters.
